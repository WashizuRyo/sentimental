# Thesis Writer

卒業論文「WRIME Ver.2を用いたLLMによるSNS投稿の感情分析」の本文を、根拠が追跡でき、既存章と矛盾しない学術文章として完成させる。

## 執筆フロー

1. ルートの `AGENTS.md` を読む。
2. `thesis/1_toc.md`、`thesis/2_intro.md`、対象章、`thesis/references.md` を確認する。関連するレビュー文書と `thesis/references/**/summary.md` も必要に応じて読む。
3. 対象節の役割、中心的な主張、必要な根拠、前後の節との接続を整理する。
4. 書式の判断が必要なら、`thesis/format/thesis_format_manual_*.pdf` の最新版を優先する。さらに詳細な規定が必要な場合だけ日本心理学会の手引きを参照する。
5. ユーザーが「案だけ」と指定しない限り、対象のMarkdownファイルを直接編集する。
6. 編集後に差分を読み、対象節の目的、前後関係、研究設定、用語、数値、引用を確認する。

## 章ごとの役割

- 序論では、研究背景、先行研究上の不足、研究目的を接続する。
- 関連研究では、先行研究を整理し、本研究の位置づけと比較設計へつなげる。
- 実験方法では、第三者が条件を再現できる具体性を確保する。
- 結果では観測事実を記述し、解釈と分ける。
- 考察では結果に基づく解釈、限界、含意を区別し、結果にない断定を避ける。
- 結論では研究目的への回答を示し、新しい主張や結果を持ち込まない。

## 執筆原則

- 簡潔で明確な常体を使い、既存本文の語彙、句読点、見出し階層、引用表記に合わせる。
- 1段落に中心的な主張を1つ置き、主張、根拠、本研究との関係を自然につなぐ。
- `AGENTS.md` の研究設定を権威ある基準とし、2値分類へ変更しない。
- `Zero-Shot`、`LoRA`、`フルファインチューニング`、`書き手`、`感情極性`、`QWK`、`Accuracy`、`MAE`などの表記を章間で統一する。
- 依頼範囲外の章やユーザーの既存変更を書き換えない。

## 根拠と引用

- 事実的主張、数値、先行研究の結論に根拠を対応させる。
- 出典、著者、年、数値、実験結果、ページ番号を推測しない。
- `summary.md` は文献探索の補助に使い、重要な主張、数値、直接引用は可能な限り原論文PDFで確認する。
- ローカル資料で確認できない内容を断定しない。必要な文献が不足する場合は、架空の引用で埋めず不足を明示する。
- 未実施の実験、未確認の結果、存在しない分析を作らない。結果が必要な節で入力がなければ、必要な情報を具体的に示す。
- 引用文献が `thesis/references.md` に存在するか確認する。書誌情報を検証できない文献を追加しない。

## 完了報告

- 編集したファイルと、追加・変更した内容を簡潔に示す。
- 根拠不足、実験結果待ち、判断が必要な箇所を明示する。
- 引用の独立検証が必要なら `citation-reviewer`、章間の独立レビューが必要なら `consistency-reviewer`の利用を提案する。
