# 3. 実験方法

## 3.1 タスク設定

　本研究では，日本語SNS投稿から書き手本人の感情極性を予測する5クラス分類を扱う。ラベルは−2（強いネガティブ），−1（ネガティブ），0（中立），+1（ポジティブ），+2（強いポジティブ）であり，順序関係を保持したまま評価する（Suzuki et al., 2022）。モデル内部では各ラベルをクラスID 0から4へ対応させ，評価時に元の数値へ戻す。

　三手法では，同じGemma 3モデルを用い，同一の予測対象，テストデータ，評価指標で比較する。ただし，ゼロショットはラベル文字列を生成するのに対し，LoRAおよびフルファインチューニングは5クラスの分類ヘッドから予測する。

## 3.2 使用データセット

　WRIME Ver.2は，35,000件の日本語SNS投稿に書き手と読み手の感情ラベルを付与したデータセットである（Suzuki et al., 2022）。本研究では，Hugging Face Datasetsのload_dataset関数を用いて，shunk031/wrimeのver2を取得する。各投稿の本文をモデルへの入力とし，書き手本人が付けた5段階の感情極性を正解ラベルとする。データセットに含まれる読み手のラベルと8種類の感情強度ラベルは使用しない。

　公式分割に従い，学習30,000件，検証2,500件，テスト2,500件を用いる。各分割間で書き手は重複しない（Suzuki et al., 2022）。学習データは，LoRAおよびフルファインチューニングのパラメータ更新に用いる。検証データでは，各エポック終了時に保存したチェックポイントのQWKを算出し，最も高いチェックポイントを選ぶ。選択したチェックポイントを用いて，テストデータで最終的な分類性能を評価する。ゼロショットには学習・検証データを与えない。

## 3.3 使用モデル

　本研究では，Googleの指示調整済みモデルGemma 3 270Mを使用する。Hugging Face上のモデル識別子はgoogle/gemma-3-270m-itである。同モデルは約2億7,000万パラメータの軽量モデルであり，タスク固有のファインチューニングを想定して設計されている（Lacombe et al., 2025）。限られた計算資源でも，ゼロショット，LoRA，フルファインチューニングを同じモデルで比較できるため採用した。

　ゼロショットでは，モデルに感情極性ラベルを文字列として出力させる。LoRAおよびフルファインチューニングでは5クラスの分類ヘッドを追加し，同じ初期モデルからそれぞれ独立に学習する。

## 3.4 比較手法

　三手法には同じGemma 3モデルを用いる。テストデータは最終評価にのみ使用し，その正解ラベルをプロンプトや学習条件の設定に用いない。また，ゼロショットでは検証データの正解ラベルも使用しない。

　ゼロショットでは，学習例を含まない次のプロンプトを用いる。

> 次のSNS投稿に表れている，書き手本人の感情極性を分類してください。  
> ラベルは，-2（強いネガティブ），-1（ネガティブ），0（中立），+1（ポジティブ），+2（強いポジティブ）の5段階です。  
> 回答は「-2」「-1」「0」「+1」「+2」のいずれか一つだけを出力してください。  
>   
> SNS投稿：{投稿本文}  
> 回答：

　プロンプト中の「{投稿本文}」を各投稿の本文に置き換え，モデル付属のチャットテンプレートへ入力する。また出力を5種類のラベルに限定する。

　LoRAではモデル本体を固定し，LoRAパラメータと分類ヘッドを学習する（Hu et al., 2022）。学習後は更新量をモデル本体へ統合する。フルファインチューニングでは，全パラメータと分類ヘッドを学習する。

　主な学習条件を表1に示す。

**表1　ファインチューニングの学習条件**

| 設定項目 | LoRAファインチューニング | フルファインチューニング |
|---|---:|---:|
| 学習対象 | LoRAパラメータと分類ヘッド | 全パラメータと分類ヘッド |
| エポック数 | 3 | 3 |
| バッチサイズ | 32 | 32 |
| 学習率 | $2 \times 10^{-4}$ | $2 \times 10^{-5}$ |
| 最大入力長 | 512 | 512 |
| 演算精度 | FP16 | FP16 |
| 乱数シード | 42 | 42 |
| LoRAランク | 8 | 該当なし |
| LoRAスケーリング係数 | 32 | 該当なし |
| LoRAドロップアウト率 | 0.1 | 該当なし |

## 3.5 評価指標

　分類性能の主指標にはQWK，補助指標にはAccuracyとMAEを用いる。QWKは偶然の一致とラベル間の距離を考慮した一致度，Accuracyは正解した事例の割合，MAEは正解ラベルと予測ラベルの平均距離を表す。QWKとAccuracyは値が高いほど，MAEは値が低いほど分類性能が高い。

　学習コストは，更新対象パラメータ数，検証を含む3エポックの総学習時間，学習時の最大GPUメモリ使用量で評価する。総学習時間にはデータ取得，前処理，チェックポイントの保存時間を含めない。ゼロショットは追加学習を行わないため，更新対象パラメータ数と学習時間を0，学習時の最大GPUメモリ使用量を該当なしとする。

## 3.6 実験環境

　実験はGoogle Colaboratory上で行い，NVIDIA T4 GPUを1基使用する。実装にはPythonとPyTorchを用いる。モデルとトークナイザの読み込み，学習，推論にはTransformers，データセットの取得と前処理にはDatasets，LoRAの適用にはPEFT，評価指標の算出にはscikit-learnを使用する。再現性を確保するため，最終実験時には各ソフトウェアとCUDAのバージョン，モデルのリビジョン，GPUのメモリ容量，実行日時を記録する。
