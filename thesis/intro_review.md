## 重要度が高い指摘

### 1. 研究ギャップの根拠をもう少し具体化する

該当箇所: `intro.md` 1.1

「日本語感情分析におけるZero-Shot，LoRA，およびフルファインチューニングの比較検証は十分に行われていない」という主張は重要だが，現状では根拠がやや薄い。

WRIME を用いた既存研究や，日本語感情分析モデルに関する研究を簡単に整理した上で，次のように限定して述べると説得力が上がる。

> しかし，WRIME Ver.2 を用いた日本語SNS投稿の5段階感情極性分類において，Gemma 3 270M を対象に，Zero-Shot，LoRA，およびフルファインチューニングを同一条件で比較した研究は十分に見られない。

### 2. 計算コストの評価軸を明確にする

該当箇所: `intro.md` 1.3

本文では計算コストとして「学習時間」および「学習可能パラメータ数」を比較するとしている。LoRA とフルファインチューニングの比較では，これに加えて GPU メモリ使用量を含めると，研究目的との対応がより明確になる。

候補となる比較軸:

- 学習時間
- 学習可能パラメータ数
- peak GPU memory
- GPU hours
- 推論時間
- 推論時メモリ使用量

卒論の実験環境で取得しやすい指標に絞るなら，主に「学習時間」「学習可能パラメータ数」「peak GPU memory」を比較対象にするとよい。
